# Slow Pitch Softball App

A React Native mobile application for tracking slow pitch softball games, batting averages, and team statistics.

## Features

- Google OAuth authentication
- Multi-team support
- Live game scoring
- Player statistics tracking
- Batting average calculations
- Scorebook management

## Setup

1. Install dependencies:
```bash
npm install
```

2. Set up environment variables:
```bash
cp .env.example .env
```

Fill in your Supabase URL, anon key, and Google Client ID.

3. Start the development server:
```bash
npm start
```

## Tech Stack

- React Native with Expo
- TypeScript
- Supabase (PostgreSQL)
- Google OAuth
- React Navigation
